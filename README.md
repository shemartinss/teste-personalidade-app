# Aplicativo de Teste de Personalidade Big Five

Este é um aplicativo web construído com Next.js para aplicar o teste de personalidade Big Five, capturar leads, gerar um relatório em PDF e enviá-lo por e-mail.

## Funcionalidades

*   Teste de 120 itens do Big Five
*   Captura de leads (Nome, E-mail, Telefone)
*   Armazenamento de dados no Supabase
*   Geração de relatório PDF personalizado
*   Integração com ActiveCampaign para sincronização de contatos
*   Envio de e-mail transacional com PDF via Postmark
*   Design responsivo com tema claro/escuro (Boho Chic)

## Implantação

Este aplicativo está configurado para ser implantado na Vercel a partir deste repositório GitHub.
